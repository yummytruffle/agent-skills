# Session page template

Use this exact section order for every session page. If a section has no content, write `None identified` or omit it consistently; do not invent details.

- Outcome:

## 02 — Context & Objectives

- Relevant assumptions:

## 03 — Key Decisions

- ID:
- Decision:

- Rationale:
- Alternatives considered:
- Scope and constraints:
- Source evidence:

## 04 — Key Findings & Insights

- Evidence/source:

- Limitations:

## 05 — Action Items
For each item:
- Task:
- Owner: only if explicit
- Status: Open / In Progress / Done / Blocked / Unknown
- Due date: only if explicit
- Dependencies:

## 06 — Open Questions
- Question:
- Why unresolved:
- Evidence needed / next step:

## 07 — Related Memories
Show or list related Shared Memory pages and their status. Do not duplicate the full memory body here.

## 08 — Full Transcript
Preserve message order and roles, with timestamps if available:
- `[timestamp] USER: ...`
- `[timestamp] ASSISTANT: ...`
- `[timestamp] TOOL (<tool name>): ...`

For attachments or multimodal content, include a faithful available representation or a reference and note limitations. Never invent hidden tool output or inaccessible media. Redact credentials and secrets. For long sessions, add numbered transcript chunks in chronological order and preserve the same Session ID.
